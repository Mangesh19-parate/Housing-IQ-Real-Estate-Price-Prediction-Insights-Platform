# Skill: Parquet & Analytics Cache Management

**Trigger:** Working with `clean_listings.parquet` or the precomputed `analytics_cache/*.json` files.

## Use this skill when
- Regenerating the canonical cleaned dataset
- Adding or updating a precomputed analytics chart's cached JSON

## Key conventions (binding for this project)
- Analytics charts read from cache, never recompute live from raw data on each page load
- Every cache file is regenerated by a documented job (see `/build-analytics-cache`), never hand-edited
- Stale-cache detection: each cache file's metadata includes the source Parquet version it was built from

## Workflow
1. Run the cache-build job after any change to `clean_listings.parquet`
2. Diff the new cache against the previous version for sanity (row counts, obvious outliers) before deploying

## Gotchas / things that have bitten us before
- Forgetting to rebuild the cache after a data cleaning fix is the most common cause of "analytics doesn't match what I just fixed" bug reports
